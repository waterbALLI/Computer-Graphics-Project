# 云岭森林公园

基于 Three.js 的交互式三维自然场景与图形学算法演示系统。

## 运行

npm install
npm run dev

生产构建使用 npm run build 和 npm run preview。

## 交互

- 轨道观察模式：鼠标拖动旋转，滚轮缩放。
- 右侧面板：调整时间、地形起伏、地形算法和网格密度。
- 地形算法：柏林噪声与简化侵蚀地形。
- 网格密度：可切换 45×45、70×70、100×100、130×130 地形网格。
- 调试图层：显示或隐藏地形线框。
- 高空观察：切换至扩大后的完整地图视角。
- 重置视角：回到默认观察位置。

## 图形学模块

- 程序化高度场地形：使用多层梯度噪声生成柏林噪声地形。
- 简化侵蚀地形：根据噪声坡度和山谷项构造视觉近似的侵蚀地貌。
- 地形网格：根据密度参数重建顶点，使用统一世界坐标采样树木和木屋高度。
- 顶点颜色与法线：按高度设置顶点颜色，并在每次重建后重新计算法线。
- 昼夜光照：时间控制太阳与月亮光照、雾色和天空渐变。
- 基础场景：程序化树木、木屋、天空背景、阴影和基础光照。
